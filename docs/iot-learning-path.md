## 📅 第 1 周：MQTT 深度 + 工业协议（最重要）

苏州 IoT 岗位 JD 里出现频率最高的两个词：**Modbus**、**OPC-UA**。

### 学习内容
| 知识点 | 为什么要学 | 怎么学 |
|---|---|---|
| MQTT QoS 0/1/2 | 工业场景数据不能丢，面试必问 | 你的项目里 MQTT 只用了默认 QoS，改成 QoS 1，写一段"为什么选 QoS1"的注释 |
| MQTT 遗嘱消息 (Will Message) | 设备掉线自动告警 | 在 sensor-handler.ts 里加 5 行代码，设备断开时自动发遗嘱消息 |
| Modbus RTU/TCP | 工业设备 90% 用 Modbus 通讯 | 在项目里模拟接入一个 Modbus 温湿度传感器（用 node-modbus 库，20 行代码的事） |
| OPC-UA 概念 | 面试能聊就行 | 看一篇 OPC-UA vs MQTT 对比文章，能说出"OPC-UA 用在车间层，MQTT 用在云边通讯" |

### 简历里新增一行
> 熟悉工业物联网通讯协议（MQTT QoS/遗嘱消息、Modbus RTU/TCP），了解 OPC-UA 与 MQTT 在工业场景的选型差异

### GitHub 更新
在 README 技术栈里加上 Modbus，MQTT 部分展开写 QoS + Will Message

## 📅 第 2 周：时序数据库

你的项目用 SQLite/PostgreSQL 存所有数据，但 IoT 场景海量传感器数据应该用时序库。

### 学习内容
| 知识点 | 怎么学 |
|---|---|
| TDengine 或 InfluxDB | 二选一。推荐 TDengine（国产、中文文档好、苏州很多公司在用） |
| 写入 + 查询 | 把你项目里的 DeviceReading 表迁移到 TDengine，写 10 条传感器数据进去，做一次"近 24 小时温度变化"查询 |

### 操作步骤
1. Docker 拉一个 TDengine 镜像：`docker run -d -p 6036:6036 -p 6041:6041 tdengine/tdengine`
2. 用 REST API 或 Node.js 驱动写入模拟数据
3. 在你的 dashboard 上加一个"近 24 小时温湿度曲线"

### 简历里新增一行
> 熟悉时序数据库 TDengine，有 IoT 传感器数据存储与聚合查询经验

## 📅 第 3 周：边缘计算

你已经有 YOLOv8 部署经验了，但简历上只有一个"98% 准确率"太单薄。这周展开。

### 学习内容
| 知识点 | 怎么学 |
|---|---|
| 边缘计算架构 | 画一张架构图：传感器 → 边缘网关（本地推理+过滤）→ 云端平台（存储+展示） |
| 边缘规则引擎 | 在你的项目里写一段"边缘预处理"逻辑——当温度超过阈值，边缘网关直接触发本地继电器断电，同时上报云端（不需要实际硬件，用代码模拟就行） |
| 带宽优化 | 写一段注释：边缘端把 25fps 视频抽帧到 1fps 再上传，带宽节省 96% |

### 简历里原有这行做升级
> ~~完成 YOLOv8 模型部署，准确率 98%+~~
> **改为**：设计边缘计算架构，实现 YOLOv8 模型在边缘网关的本地推理（8 路视频流实时分析），边缘端预处理过滤后将结构化数据上传云端，带宽占用降低 96%。配合本地规则引擎实现阈值超限自动联动（如温度过高自动断电）

## 📅 第 4 周：设备管理 / 物模型

### 学习内容
| 知识点 | 怎么学 |
|---|---|
| 物模型 (Thing Model) | IoT 平台最核心的概念——把物理设备抽象成"属性 + 事件 + 服务" |
| 设备影子 (Device Shadow) | 云端存一份设备期望状态，设备上线后自动同步 |

### 操作步骤
1. 在你的项目里给每个传感器加一个物模型 JSON（属性：温度/湿度/在线状态；事件：温度超限告警；服务：设置采样频率）
2. 写一个设备注册接口：新传感器接入时，自动注册 + 下发初始化配置

### 简历里新增一行
> 理解 IoT 平台物模型与设备影子机制，有设备注册发现、配置下发、OTA 升级的实践经验

## 📅 第 5-6 周：Spring Boot / Java IoT（选学）

你之前在北京合力亿捷用的是 Java + Eclipse。苏州很多 IoT 公司后端用 Spring Boot。

### 学习内容
| 知识点 | 怎么学 |
|---|---|
| Spring Boot 基础 | 搭一个最简单的 REST API（查数据库返回 JSON） |
| Spring Boot + MQTT | 用 Spring Integration MQTT 模块收发消息 |

### 为什么选学
如果两周学不下去就别硬撑。你手上的 Vue + Express + MQTT 已经够找 70% 的 IoT 岗位了。Java 后端是你实习经验的延伸，学成了多 30% 的机会。

### 简历里一行
> 有 Spring Boot 开发经验，熟悉 Spring Integration MQTT 模块
